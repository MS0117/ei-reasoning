## Judge proposals

### Stratified Explicit-Share Absorption (SESA): per-question-normalized cliff SFT term with a design-parameter per-step share rho, a privileged late-window guess gate on rescued successes, a base-anchored displacement guard, and a mandatory held-out-cliff transfer endpoint

**loss_definition**: Setting: iteration k, student pi_theta re-initialized from base pi_0 (STaR-style). ce_t(theta) = -log pi_theta(y_t | x, y_<t). D_S = solved-question examples i (<=4 shortest correct rollouts per question, current region weights w_t). D_C = rescued successes j for converted cliff question q: n_q <= 2 deduped shortest per question, length T_j. Signals per rescue j: g'_t = log pi_0(y_t | x, y*, y_<t) - log pi_0(y_t | x, y_<t) (privileged contrast, one teacher-forced pass, already dumped); Gamma_j = (1/|W_j|) * sum_{t in W_j} max(0, -g'_t) where W_j = last third of y_j's token positions (the wrap-up/answer phase M8 identifies as the guess signature). Guess gate: omega_j = 1[Gamma_j <= tau_Gamma], tau_Gamma calibrated on existing dumps (see L0); soft variant omega_j = sigma((tau_Gamma - Gamma_j)/s_Gamma).

Terms, each with its OWN normalizer (never the shared global weight-sum, which buries a 1.9%-count slice):
L_S = [sum_{i in B_S} sum_t w_t ce_t] / [sum_{i in B_S} sum_t w_t]  (current WeightedSFT, unchanged);
L_C = [sum_{j in B_C} (omega_j / (n_q * T_j)) * sum_t ce_t] / [sum_{j in B_C} omega_j / n_q]  (per-QUESTION normalization: one converted cliff = one unit of loss regardless of its rescue count or 5.6k-token length; uniform token weights inside a rescue — no token credit, by M1-M6);
L_N (optional, mu>0) = sequence-level negative on the base's OWN modal-wrong failure rollouts F_q (v0: existing sft+dpo path with rejected = modal-wrong sample; v1: bounded unlikelihood sum_t -log(1 - pi_theta(y_t)) per-question-normalized);
L_G (on iff mu>0) = [sum_{j in B_C} (omega_j/n_q) * max(0, mean_t ce_t(theta) - mean_t ce_t(theta_0))] / [sum_j omega_j/n_q]  (displacement guard: rescued successes must not become less likely than under base theta_0; mean_t ce_t(theta_0) is free from the C(y) scoring pass).

Total: L = (1 - rho) * L_S + rho * (L_C + mu * L_N + 1[mu>0] * L_G), rho in {legacy ~0.05, 0.1, 0.3}, mu in {0, 0.1, 0.3}. rho is REALIZED, not just averaged: stratified sampler puts exactly m_C = 1 D_C example in every global batch of 32 (round-robin over D_C), so the cliff term is present at every optimizer step instead of the current bursty pattern (absent from >half of grad-accum windows, one 5k-token sequence dominating the rest). Curriculum: rho held fixed across iterations while D_C accumulates STaR-style; transfer is judged at >=2 iterations (dip-and-recovery evidence). Mandatory endpoint for any arm: held-out cliff set B (never trained, improve run once) — avg@32 and attractor mass P(modal wrong answer) vs base re-roll noise floor — plus envelope (non-cliff holdout, AIME/MATH500-hard canary, D_C NLL as memorization index, length drift).

**signals_used**: verifier correctness (the only sign; selects D_C and F_q); privileged contrast g'_t restricted to the LAST THIRD, aggregated to a per-sequence scalar Gamma_j (guess gate) — never a token weight; student and base per-token NLL from the existing C(y) scoring pass (S_mean/S_tail selection, displacement guard, memorization index); per-question rescue count n_q and modal-wrong-answer identity from rollout/improved.jsonl (normalization, optional negative, attractor-mass endpoint); dataset counts (token/example share) to realize rho via the stratified sampler

**supported_by**: M1 + M6: the adapter's effect is a diffuse sequence-level shift (+63..+200 nats) and 92-96% of per-token ratios sit inside any clip — off-policy-ness lives at the sequence level, so the correct granularity for any treatment of rescues is the sequence/mixture level, and uniform token weights inside L_C are the right default; M10 + decision-doc arithmetic: cliff examples are 1.9% by count / ~5.7% by tokens, the global weight-sum normalizer makes any cliff-specific signal numerically invisible (solution=0.2 only reaches ~8%), and the cliff term is absent from >half the accum windows — a separately-normalized term with stratified per-step supply is the only fix; region tags for it already exist; M8 + M9: the ONLY Bonferroni-surviving discriminative signal is late-window negative g' mass, and M8 shows it is precisely a give-up/guess-phase detector (70% prose, 3% number tokens, +0.55 nat last-decile excess) — exactly the signature a verifier-PASSING lucky guess should carry; with the majority of conversions being 1-of-24 successes and LSPO itself flagging answer-space guessing as an open risk, a sequence-level guess gate is the one place this signal is verifier-COMPLEMENTARY rather than verifier-redundant; M2 + Lambda measurements (decision doc 1.3): mean g identical on successes vs failures, exact IS weight Lambda is a length statistic (Spearman -0.82) and is larger on INCORRECT siblings (20/57 correct-larger) — this is what forces L_C to carry no reliance/importance sequence weight and makes rho a design parameter, which SESA embraces rather than estimates; Toy result STAGED 0.551 vs LSPO 0.308: the scaffold is worth keeping; SESA changes only how its output is absorbed and measured

**contradicted_by**: The guess gate's validity among SUCCESSES is unmeasured: M4/M8 separations are correct-vs-incorrect, driven by failures' final-answer phase; among verifier-correct rescues Gamma may be low-dispersion or track benign wrap-up style — this is exactly what the L0 test must establish before the gate ships (and M9's multiple-comparisons warning applies to any new paired test I run); With n_q = 1 for 54-63% of converted cliffs, gating throws away the question's ONLY rescue — the gate trades scarce cliff data for purity, the opposite of DART-Math/RASFT's up-weight-the-hard-question logic; Difficulty-tradeoff (ICML26) + HS-STaR: at ~120 examples/iteration, hard high-NLL examples hurt in expectation and boundary questions out-earn cliffs per sample — rho=0.1-0.3 may cost non-cliff performance before accumulated volume pays (the envelope may bind early); M5's conversion-neutral DPO adapter and the 107-question toy noise floor (+-6) mean the conversion-on-A metric may show nothing for ANY absorption variant; SESA's payoff claim rests on B-transfer and attractor mass, which are untested endpoints — SC-SDPO's sqrt(p(1-p)) family is the published counter-position that p=0 questions deserve zero weight at all; Long-CoT degradation evidence (Through the Valley; Kim et al.) — repeatedly training a 4B model on ~5.6k-token T=1.2 samples at elevated share risks length/entropy drift that no term in SESA actively prevents (only the envelope detects it)

(3) MIXTURE ARITHMETIC: from the frozen build_dataset, recompute cliff count/token share, fraction of grad-accum windows with zero cliff mass, and the realized per-step share under m_C=1 stratification — confirms the detectability fix binds and rho maps to a real gradient share. (4) NEGATIVE CONTROL (documents why L_C carries no other sequence weight): per-success mean-g and Lambda vs length and C(y) — expected to reproduce the length-proxy result (Spearman ~ -0.8), closing reliance/iw-SFT-style weights. **nearest_prior_work**: HDPO (arXiv:2603.23871) — separately-normalized lambda-weighted cliff term; but distills teacher-sampled bridges via JSD, never adapter-rescued gold-free samples, no transfer test; SRPO sample routing (arXiv:2604.02288) — per-route normalization pattern for the detectability problem; LSPO (arXiv:2607.27787) — the scaffold itself; student side is inert per-token IS, discards the guessing risk it names, no held-out-cliff transfer; iw-SFT (arXiv:2507.12856) — sequence-level importance weights on filtered SFT data; rejected here because the exact weight is exp(Lambda) ~ 0 and Lambda is a length statistic (decision doc 1.3); RASFT (arXiv:2606.07006) / DART-Math (arXiv:2407.13690) / SFT-GO (arXiv:2506.15021) — published sequence/group up-weighting of hard questions; none handle scaffold-rescued all-fail prompts or gate by a privileged signal; SC-SDPO (arXiv:2605.27765) — the counter-position (p=0 questions get zero weight); FiRe-OPD (arXiv:2606.02684) — trajectory filter by teacher likelihood (the C(y)-as-filter precedent); DFT/EAFT/ProFit (arXiv:2508.05629, 2601.02151, 2601.09195) — class-B token down-weighting, explicitly rejected: DFT loses ~6 math points on Qwen3-4B-Instruct and its own authors flag failure on beyond-capability content, which is the definition of a rescue; GLOW (arXiv:2601.04992) / RIFT (arXiv:2601.09253) / NSR (arXiv:2506.01347) — the published forms of the optional attractor negative; Rethinking Generalization in Reasoning SFT (arXiv:2604.06628) — dip-and-recovery, mandating >=2-iteration transfer reads

**novelty_claim**: The loss algebra is honestly HDPO-lambda + stratified routing + a hinge guard — published patterns. ### Terminal-Phase Attractor Unlikelihood (TPAU): plain SFT on rescued successes + a separately-normalized, g'-gated unlikelihood term confined to the terminal answer-emission/give-up span of the base's own on-policy failures

**loss_definition**: L = L_SFT + lambda_neg * L_TPAU. L_SFT is the existing WeightedSFTTrainer loss, unchanged: (sum over batch tokens w_r(t)*CE_t)/(sum w_r(t)), CE_t = -log p_theta(y_t|x,y_<t), w_r the region weights (solution for solved, continuation for rescued-cliff successes). L_TPAU = [ sum_x sum_{y in F_x} sum_t m_t * u_t * ( -log(1 - p_theta(y_t|x,y_<t)) ) ] / [ sum_x sum_y sum_t m_t * u_t ] — its own normalizer (SRPO/HDPO-style routed term), lambda_neg ~ 0.05–0.15. Symbols: x = a cliff question with >=1 rescued success in the current dataset; F_x = the BASE policy's own failed rollouts for x from the rollout stage (up to 8; exactly on-policy for the student since train.init_from=base; optionally restricted to rollouts emitting the modal wrong answer = the attractor); y_t = token t of failure y, T=|y|; p_theta = student probability. Mask m_t = 1[t >= t_box - 20 OR t/T >= 0.8] * 1[g'_t <= -tau] * 1[protect_t = 0], where t_box = index of the first "boxed" token (fallback 0.8T if absent; measured first-box location 0.88); g'_t = log p_base(y_t|x⊕y*,y_<t) - log p_base(y_t|x,y_<t), one teacher-forced pass under the frozen base with gold y* shown (existing privileged scoring mode); tau ~ 0.5 nat, tuned at L0 so the mask covers <=10% of failure tokens; protect_t = 1 iff the token-id 4-gram y_{t-3..t} occurs in any rescued success of the same question (text-level NTHR guard against likelihood displacement of the successes' own answer emission). Magnitude u_t = min(-g'_t, c)/c in (0,1], c = 3 nats — privileged disagreement sets MAGNITUDE only; the verifier set the SIGN by putting y in F_x (RLSD/OPPO principle). -log(1-p) is Welleck unlikelihood: bounded, gradient vanishes as p->0, no RIFT-style divergence on off-support tokens. Watchdog (logged, not optimized): mean delta log p_theta of the same question's rescued successes vs the no-negative arm; decay lambda_neg if it drops below the SFT-only trajectory (DPOP-style displacement guard).

**signals_used**: verifier outcome labels (sign only: membership in F_x; identity of the modal wrong answer); privileged NEGATIVE contrast g'_t on failures (span gate + clipped magnitude) — the only Bonferroni-surviving token-discriminative signal (M9); token position / first-\boxed location (M8: class-discriminative excess lives entirely in the last decile; first box at 0.88); sibling rescued successes' token 4-grams (protection mask only, never credit); base policy's own failed rollouts (free, on-policy for the student per M10); NOT used: adapter contrast g (dead, M1–M3), positive g' (n.s., M4), entropy/surprisal weights (n.s. after Bonferroni, M9; DFT-family harmful on this base)

**supported_by**: M4: negative privileged mass separates correct from incorrect at sequence level, paired 43/59 p=6e-4 and 46/57 p=3e-6 — the strongest surviving signal, and TPAU uses only its negative side on failures; M8: the paired excess is +0.557/+0.546 nat/token in the LAST decile and ~0 in deciles 1–9; worst windows are literally the give-up/guess phase; first \boxed at 0.88 — this hands me the mask rule (terminal window ∧ g'<=-tau) instead of a heuristic; M9: G_neg and worst-window LOCATION are the only tests surviving Bonferroni — every signal TPAU consumes is a survivor, everything it discards is not; M2: successes and failures are token-profile identical over the body — uniform negatives on 5k tokens would displace successes (CHES logic), so localization is REQUIRED, which is exactly what TPAU adds over NSR/UFT; M6 + TOPR arithmetic: off-policy-ness is sequence-level; adapter failures carry ~zero usable negative weight (ratio exp(-63..-200)) — hence negatives go on the base's own 8/8 failures (M10: free and on-policy for a student that re-inits from base); M10: region-weight machinery exists; a separately-normalized cliff term needs only a small train.py change; separate normalization solves the 1.6% detectability problem (HDPO-lambda/SRPO pattern); M5: whole-sequence pairwise negatives (DPO on chosen=bridge/rejected=own-failure) were conversion-neutral — supporting phase-localized unlikelihood over repeating any whole-sequence pairwise construction

**contradicted_by**: M8's own punchline cuts hardest: the discriminative signal coincides with what the verifier already provides (wrong final answer + the guessing loop). TPAU is PHASE-level credit, not route-level; it can unlearn the attractor-emission behavior but cannot teach the correct route. I state plainly: on these measurements, route-level token credit in the reasoning body (deciles 1–9) is CLOSED for every self-contained signal we have.; M5: the one failure-side lever already tried (sequence DPO vs own failures) was conversion-neutral — a real prior that the negative side may not move conversion at all; that is why my endpoints are attractor mass and held-out-B, not conversion.; M2 was measured on ADAPTER samples; 'base failures share the attractor/token profile' is inferred (the decision doc admits this), not measured — L0's proxy use of adapter failures inherits this gap.; NSR's mechanism redistributes suppressed mass to the model's other plausible continuations — on a cliff with 70% mass on one wrong answer, the beneficiary may be the second wrong answer, not the truth.; Toy noise floor: 107 questions, ±6 is noise; even a directionally-correct negative term can be invisible in one arm (mitigated by the continuous attractor-mass endpoint, but not eliminated).; Suppressing give-up prose risks teaching 'never conclude' (answer-emission suppression, length blowup) — the protection filter and format-token accounting are unproven until L0; OPD-Compaction also warns that training on failures in long traces is delicate.

**L0_test**: New CPU script scripts/diag_terminal_mask.py over the EXISTING priv dumps (runs/toy_cliff/default_STAGED_20260819_121856/iter_0/diag_credit_priv and default_STAGED_20260821_193219/iter_0/diag_credit_priv: tokens.jsonl fields key/pos/tok/g(=g')/s/H joined to candidates.jsonl correct/qid; ~200 candidates each). Build m_t exactly as in the loss (first-'boxed'-minus-20 or last-20% window, g'<=-tau sweep tau in {0.3,0.5,1.0}, 4-gram protection vs same-question successes), using incorrect adapter candidates as the stated proxy for base failures. NO training. Pass/fail gates: (1) Localization efficiency — paired sign test of masked mass sum(m*u*(-g')) on failures vs the identical rule applied to successes; PASS iff p<=0.01 on BOTH runs while masking <=10% of failure tokens (i.e., ~the full-sequence G_neg separation of 43/59 / 46/57 retained at <=1/10 of the token budget — that concentration IS the credit claim). (2) Displacement bound — after protection, fraction of masked failure positions whose token also occurs in the last two deciles of any same-question success; PASS <=20%; also report masked mass on pure-format tokens (must be well under the 26% anatomy share). (3) Attractor coverage — share of failures whose masked span contains that question's modal wrong-answer string; PASS >=60%. (4) Free kill-check for the sibling-localizer alternative: median first-divergence position (token-id longest common prefix) between each failure and nearest same-question success; if <5% of length (expected at T=1.2), record sibling-divergence localization as dead. Any of (1)-(3) failing => primary fails => secondary recommendation.

**nearest_prior_work**: Welleck et al. 1908.04319 — token unlikelihood, the loss primitive (rule-located candidates, no verifier); UFT 2504.11364 — unpaired verifier-only unlikelihood inside SFT, deliberately UNlocalized; NSR / W-REINFORCE 2506.01347 — on-policy negatives on the same base family, uniform over tokens; OGLS-SD 2605.12400 — location-aware failure signal, but on the PREFIX (first 1024 tokens), the opposite location from what M8 measures here; HSD 2606.15576 — failure credit localized via a sibling-success-conditioned teacher (distillation, not unlikelihood; no cliffs); cDPO 2411.19943 — rejected-side-only token weighting from a model contrast; NTHR 2505.18830 / CHES 2410.08847 / DPOP 2402.13228 — displacement guards; my 4-gram protection is the text-level analogue; RLSD 2604.03128 / OPPO 2605.21851 — verifier owns sign, privileged contrast owns magnitude; HDPO 2603.23871 / SRPO 2604.02288 — separately-normalized cliff/routed term (the lambda mechanics); RIFT 2601.09253 — bounded negative objective without pairs

**novelty_claim**: First objective to use a gold-conditioned privileged self-teacher purely as a WHERE — a span gate on the terminal answer-emission/give-up phase of the policy's own on-policy failures — with the verifier as the only sign, unlikelihood as the primitive, and a sibling-success n-gram exclusion as the displacement guard, in an EI/SFT student on cliff prompts with attractor-mass and held-out-cliff-transfer endpoints. Published location-aware failure objectives point at the prefix (OGLS-SD, D2PO decay) or at sibling divergence (HSD); none derives its mask from a measured class-discriminative LOCATION statistic, and none guards displacement lexically. Equally part of the claim: the measured negative result that route-level token credit in the reasoning body is unidentifiable from every self-contained signal here (deciles 1–9 carry zero class-discriminative disagreement) — no cited paper tests or reports this.

**implementation_delta**: 1) scripts/diag_terminal_mask.py (new, CPU-only, L0). 2) One privileged teacher-forced scoring pass over base failure rollouts per iteration via the existing engine.py privileged mode (small GPU cost; g' never enters prompts, only weights — passes the leakage/learnability-gate contract since conditioning is scoring-side only). 3) build_dataset: for converted cliffs, additionally emit the base failure rollouts as examples whose tokens carry a new region label 'negative' with per-token weight m_t*u_t (masks computed on response_token_ids — token-id splicing invariant respected; unmasked failure tokens get weight 0 => -100). 4) train.py WeightedSFTTrainer: ~20-line change — tokens in region 'negative' contribute -log(1-p) into a separately-normalized auxiliary sum scaled by new config train.sft.negative_lambda; log the success-log-p watchdog per cliff qid; extend tests/test_loss_invariance.py to cover the two-normalizer loss. 5) filters.py, lora_fit.py, DPOTrainer: untouched. No anchor machinery, no MC rollouts, no external judge.

**expected_effect_and_risk**: Expected effect: not conversion (M5 says the failure lever was conversion-neutral) but de-sharpening the absorbing wrong mode — primary endpoints are attractor mass P(modal wrong answer) on trained cliffs A AND held-out cliffs B (continuous, moves even when pass@32 stays 0), pass@k spread, and the A->B transfer dose-response the decision doc already commits to; TPAU is the localized upgrade of that doc's sequence-level S4 negative. Plausible magnitude: small — the span is ~5-10% of ~5k tokens on ~120 questions; the separate normalizer makes it detectable but the toy noise floor may still swallow it. Risks: (i) answer-emission suppression / never-concluding (capped lambda_neg, protection filter, non-cliff + MATH500-hard canary, length-drift monitor); (ii) likelihood displacement of successes' terminal phase (L0 gate 2 + training watchdog); (iii) mass redistribution to the second wrong answer rather than the truth (attractor-mass endpoint detects this: watch P(top-2 wrong) not just P(top-1)); (iv) the mask degenerating to 'punish the wrong digits', duplicating the verifier (anatomy says only 3% of the mass is numeric — most is the guess-loop prose, a behavior worth unlearning).

**confidence**: 0.5

**secondary_recommendation**: If L0 fails gate (1) (the terminal mask does not concentrate the class separation) or gate (2) (displacement bound violated), declare span/token-level credit assignment CLOSED on this data — write that up as the measured negative result, it is publishable and no cited paper reports it — and fall back to the minimal displacement-safe form of the decision doc's sequence-level negative: bounded RIFT/NSR-style unlikelihood applied ONLY to the wrong-answer content tokens inside \\boxed{...} of the base's modal-wrong-answer failures (a handful of string-matched tokens, no g', no span, same separately-normalized lambda term), with the entire remaining novelty budget spent on the sequence-level absorption objective and the A->held-out-B transfer dose-response with attractor-mass endpoint — which is where the 2026-08-23 decision doc already placed the claim.


### OPAL — On-Policy Attractor unLikelihood: level-matched off-policy cliff loss (uncorrected SFT on rescued successes + bounded, verifier-localized unlikelihood on the base's own on-policy failures at the attractor-answer span)

**loss_definition**: Per cliff question x (0/8 base rollouts): S(x) = kept verifier-correct adapter-rescued trajectories (m~2-3, token ids y^r); a^-(x) = modal verifier-extracted final answer among the 8 base failures (exists with share>=0.25 in 93.5% of cliffs, mean share 0.65; if absent, negative term skipped); F^-(x) = the base failures whose extracted_answer == a^-(x) (on-policy for the student, which re-inits from base); A_j = token-id span of the final \boxed{a^-} occurrence in failure y^j's response_token_ids (id-located, never re-tokenized; optional kappa-weighted extension to boundary-clean inline a^- mentions in the last decile, default kappa=0). Loss: L = L_pos + lambda*L_att. L_pos = sum_x sum_{r in S(x)} sum_t -log p_theta(y^r_t | x, y^r_<t) / N_S — plain CE under existing continuation region weights, N_S = the trainer's global weight sum. NO importance correction anywhere: per-token ratio set to 1 (M6: 92-96% of tokens inside the DAPO clip, correction numerically inert) and sequence ratio set to 1 by TOPR's positive branch — E_mu[R log pi_theta] is a valid lower bound on J(theta) for ANY behavior policy mu when R>=0, and tightening it with the true sequence ratio pi_theta/pi_s = exp(-(63..200)) gives effective sample size ~0, so the TOPR bias is the only estimator carrying information. L_att = sum_x sum_{j in F^-(x)} sum_{t in A_j} -log(1 - p_theta(y^j_t | x, y^j_<t)) / N_A, p clamped <= 1-delta (delta=0.02), N_A = total attractor-span tokens in the global batch — a SEPARATE normalizer (SRPO/HDPO routing) so the 1.6% cliff slice is not diluted. Gradient w.r.t. the realized-token logit is +p_t <= 1 (bounded, RIFT-consistent); measured p ~= 0.99 at these spans, so the update concentrates exactly on the confident wrong-answer commitment, and the NSR redistribution shape (-p_theta(v) on competing logits) moves mass to the model's own plausible alternative answers. lambda in [0.1,1], default 0.3. Adapter-sampled failures NEVER enter: their TOPR-truncated sequence ratio is exp(-(63..200)) ~= 0 (zero licensed negative weight; also only 26% still box a^-), whereas base failures carry ratio == 1 exactly at init (pi_theta = pi_base), so their negative gradient is on-policy-licensed.

**signals_used**: verifier verdicts + per-sample extracted_answer from partition/verdicts.jsonl (base rollouts); modal wrong answer a^-(x) per cliff (attractor); response_token_ids id-span location of the final \boxed{a^-} (token-id splicing invariant); student in-graph token probability p_theta (for the bounded unlikelihood); on-policy-ness of base failures via train.init_from: base; explicitly NOT g, g', H, or s as loss signals (used only in L0 diagnostics)

**supported_by**: M6: per-token IS inert (92-96% inside clip) and sequence IS annihilating (exp(-63..-200)) -> the only defensible off-policy 'correction' is set-selection (which trajectories, which sign), i.e. ratio=1 on rescued positives and exclusion of adapter failures; this is the lens question answered by measurement; M8+M9: the only Bonferroni-surviving class signals are negative-g' mass and its last-decile location = the wrap-up/commit phase around the wrong answer; M8's own conclusion ('the teacher knows the ANSWER, not the route') says localize the negative by the verifier's answer, not by g' — which OPAL does with zero model passes; M2+M5: success/failure token profiles identical everywhere else and whole-sequence DPO neutral -> a negative must be span-localized on the one provably-differing token class (the committed wrong answer); the span restriction IS the likelihood-displacement guard; M10: 8 free on-policy failures per cliff; per-token weight plumbing exists (train.py loss_weights, global weight-sum normalizer); separate normalizer fixes the 1.6% detectability problem; M1 + pilot runs today: boxed-answer tokens are ultra-confident (M1 s~0.11; measured boxed-a^- span mean p=0.99, s=0.009) and g~0.02 — the adapter did not remove the attractor and SFT-on-rescues doesn't move it (decision doc), so an explicit negative is the only lever aimed at the measured pathology; attractor confirmed on this repo's verdicts: modal share mean 0.65, 72% of cliffs >=0.5, 93.5% >=0.25

**contradicted_by**: M8: number/answer tokens carry only ~3% of failures' negative-g' mass (70% prose) — the measured teacher-disagreement mass is the guess-loop prose, which OPAL deliberately excludes for displacement safety; if the causal attractor lives in the route/prose rather than the answer commitment, the boxed-span negative under-covers it; Decision-doc fact 'rescue training does not move the attractor' shows positives don't fix it but is NOT evidence a boxed-span negative moves conversion; the objective may only teach answer-avoidance/hedging (attractor mass drops, conversion flat); M2 profile identity implies NTHR-style gradient coupling through near-identical hidden states ('Thus, the answer is \boxed{...}') can still displace successes' correct-answer commitments at the same positions; Pilot today: 6% of correct adapter candidates matched boxed==a^- under loose any-boxed normalization — residual verifier-equivalence/normalization noise in answer matching (math_strict quirks) that the final-box + verdict-keyed rule must eliminate; HS-STaR / SC-SDPO / RAFT family: p-hat=0 questions may be low-utility per unit compute regardless of objective — the whole cliff program could under-deliver vs boundary questions

**L0_test**: CPU-only, existing files, no training; steps 1 and partial 2-4 ALREADY EXECUTED this session on run default_STAGED_20260819_121856. (1) From partition/verdicts.jsonl: per-cliff modal wrong-answer share; PASS bar >=0.25 share on >=80% of cliffs — measured 93.5% (mean 0.65, 72% of cliffs >=0.5): PASS. (2) From rollout/rollouts.jsonl: locate final-\boxed{a^-} id-spans in F^- failures; PASS bar: >=1 span in >=95% of F^- and mean p=exp(-s) at span tokens >=0.5 (proxy measured on adapter candidates' diag_credit_priv tokens.jsonl: p=0.99, so the unlikelihood gradient p_t is maximal exactly there): PASS pending the trivial rollouts-side span count. (3) Displacement guard: rate at which the normalized a^- string occupies the final-boxed span of the SAME question's CORRECT candidates; PASS bar <10% — loose any-boxed matching gave 6%, naive all-occurrence string matching gave 44-49% leakage (which is WHY the loss keys on verdict-extracted answers + final-box spans, not string search); recheck with the strict rule, expect ~0. (4) Record the pre-training attractor-mass baseline for the dose-response endpoint: fraction of incorrect adapter candidates boxing a^- = 0.26, late inline mention = 0.41, base-rollout modal share 0.65. FALSIFIED if (1) or (2) fails or strict-rule (3) exceeds 20% -> switch to secondary.

**nearest_prior_work**: NSR / W-REINFORCE (arXiv:2506.01347): on-policy negatives, uniform over tokens, RL — no localization, no EI/cliff, no off-policy partition; TOPR (arXiv:2503.14286) + AsymRE (arXiv:2506.20520): the asymmetric off-policy arithmetic OPAL instantiates (ratio=1 on positives, taper->0 on off-policy negatives) — sequence-level only, no localization, no cliffs, no SFT student; UFT (arXiv:2504.11364): unlikelihood on failures inside SFT — explicitly unlocalized; LSPO (arXiv:2607.27787): same scaffold; discards adapter failures by intuition (OPAL by estimator), positives via numerically-inert clipped IS, no negative term on cliffs, estimator characterization deferred; CEPO (arXiv:2605.19436): wrong-answer used as a teacher-prompt contrast, not an unlikelihood target; RL, multimodal; RIFT (arXiv:2601.09253): bounded negative penalty, sequence-level, no localization; Welleck et al. unlikelihood (arXiv:1908.04319): the primitive, rule-based candidate sets; OREAL (arXiv:2502.06781): token credit on negatives from a learned failure predictor (needs a trained credit model); repo docs/objective_decision_20260823.md 'attractor negative': OPAL is its off-policy-licensed, span-localized instantiation

**novelty_claim**: First student objective that (i) selects the negative SET by off-policy arithmetic — the base's own 8/8 rollout failures enter (exactly on-policy for a base-re-init STaR student, ratio=1), all adapter-sampled failures are excluded because their TOPR-tapered sequence ratio is exp(-63..-200)~0 — and (ii) localizes the negative gradient by a purely verifier-derived target: the id-span of the committed modal wrong answer (the measured attractor) in each failure, with bounded unlikelihood in a separately-normalized cliff term; while the positives (rescued successes) are learned with deliberately NO off-policy correction, a bias chosen by an effective-sample-size argument rather than assumed. No published method penalizes attractor-answer spans of on-policy failures inside an SFT student (the family localizes by judges, PRMs, MC rollouts, or teacher contrasts, or does not localize), and none reports the attractor-mass dose-response or cliff A->B transfer endpoints.

**implementation_delta**: filters.py: new scoring/selection fn computing a^-(x) and F^-(x) from partition/verdicts.jsonl (extracted_answer, correct) and locating final-\boxed{a^-} id-spans on rollout/rollouts.jsonl response_token_ids (id-level matching, splice invariant respected). build_dataset: emit per converted cliff (ablation arm: all 107 cliffs) new source="attractor" examples — prompt_token_ids + the failure's response_token_ids with per-token weights 0 everywhere, 1 on the A_j span (reuses the existing pre-tokenized region-annotation schema). train.py WeightedSFTTrainer (compute_loss, ~lines 106-132): tokens whose region is "attractor" route into u_t = -log(1 - p_t.clamp(max=1-delta)) instead of CE, accumulated under a second global normalizer N_A (same all-reduce pattern as the existing weight-sum) and added as lambda*L_att; config key train.sft.attractor_lambda (default 0 = exactly current behavior); extend tests/test_loss_invariance.py to the two-normalizer loss. No changes to lora_fit, DPO, or engine. One toy arm (~2.5h GPU): STAGED+OPAL vs STAGED baseline, endpoints = conversion, attractor mass (fraction of eval rollouts boxing a^-), held-out-B transfer.

**expected_effect_and_risk**: Expected: attractor mass drops measurably (the direct low-variance dose-response endpoint; baselines recorded: 0.65 of base rollouts, 0.26 boxed / 0.41 late-mention among adapter samples), while conversion on 107 questions moves within +-6 noise in a single arm — so the arm is powered for the mechanism endpoint, not the headline. Three informative outcomes: (a) attractor down & conversion up — commitment was blocking resampling of the correct route supplied by L_pos; (b) attractor down & conversion flat — the cliff is capability-limited, not commitment-limited: a clean negative result that closes the negative-side program; (c) formatting/answer-avoidance damage (monitor \boxed compliance and solved-slice accuracy on non-cliff eval; abort threshold). Risks: NTHR-style gradient coupling displacing successes' correct-answer commitments (monitor held-out rescue likelihood + a DPOP-style hinge if it moves); answer-equivalence bugs in a^- matching under math_strict normalization (the 6% loose-rule leakage must go to ~0 under the strict rule); hedging inflation at eval.

**confidence**: 0.55

**secondary_recommendation**: If OPAL fails its L0 (attractor too diffuse, spans unmatchable, or strict-rule leakage >20%): drop the negative term and run the pure level-matched positive objective — plain uncorrected SFT on ALL distinct rescued successes (RFT distinct-paths: keep every one of the 2-3, not argmin C(y)) inside a separately-normalized cliff term with its own lambda (SRPO/HDPO routing; fixes the 1.6% detectability with zero reweighting, since every token/sequence weight measured here is inert or harmful) — and spend the entire toy budget on the untested SEQUENCE-level questions: lambda dose-response and the held-out cliff-set A->B transfer endpoint, which is the cheapest unclaimed result in the whole LSPO/HDPO family and is what actually decides whether any cliff objective matters at 1.6% of the mix.

### OPAL (offpolicy): uncorrected SFT on rescued successes + boxed-attractor-span unlikelihood on the base's own on-policy failures — **weaken**

**strongest_objection**: Its one powered endpoint is circular: the loss directly minimizes p(a^-) at the boxed span and the dose-response endpoint measures p(a^-) — attractor mass WILL drop by construction, so a 'positive' result proves the optimizer works, not that commitment was the blocker. The informative endpoints (conversion, A->B transfer) sit under the 107-question +-6 noise floor in a single 2.5h arm, and OPAL's own M8 concedes the answer-span carries only ~3% of the class-discriminative mass (70% is guess-loop prose), so the mask deliberately excludes where the measured pathology lives. With OXA now published, the paper's claim narrows to 'span localization beats uniform unlikelihood' — a comparison OPAL's design does not even include as an arm.

**is_it_already_published**: Closest: OXA, arXiv 2603.16206 (verified this session) — bounded unlikelihood L_UL = -1/(N*K) sum log(1-p(s_t)) on verifier-failed trajectories selected by highest sequence confidence (lowest PPL), inside offline SFT for math, explicitly framed as 'suppressing high-confidence incorrect patterns to redistribute probability mass toward potentially correct candidates' — the confident-wrong-attractor negative in SFT, published. Second ring: UFT 2504.11364 (unlikelihood-in-SFT, deliberately unlocalized), NSR 2506.01347 (on-policy negatives, same base family), RIFT 2601.09253 (bounded penalty), TOPR 2503.14286/AsymRE 2506.20520 (the off-policy set-selection arithmetic), RL-ZVP 2509.21880 (negatives on all-fail groups). Residual: id-span localization to the modal-wrong \boxed answer, attractor identified by modal answer over 8 rollouts rather than PPL, the separately-normalized cliff term, and the on-policy-negatives-only selection rationale. That residual is a mask rule plus estimator argument — above hyperparameter level, below mechanism level.

**would_the_experiment_detect_it**: Attractor-mass drop: yes, but trivially (endpoint = training objective). Conversion: no — 1.6% cliff share is fixed by the separate normalizer, but 107 questions cannot resolve the expected small effect. Transfer: untested by design in the primary arm. Displacement/hedging side effects: detectable via the stated canaries. Net: the experiment can only confirm the uninformative outcome and is unpowered for the informative ones, and it lacks the OXA-style unlocalized control that its post-OXA novelty claim now requires.

**fix_if_any**: Do not fund standalone. Fold as SESA's mu*L_N arm with a mandatory three-way control: no negative vs OXA/UFT-style uniform unlikelihood vs boxed-span-localized — making localization the tested variable — and keep P(top-2 wrong) alongside P(top-1) to catch mass sliding to the second wrong answer.
